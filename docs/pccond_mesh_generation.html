PointCloud-Conditional 3D Mesh Generation

Continuous 3D mesh synthesis conditioned directly on sparse input point clouds ($N = 512$ with oriented normals). Stage 1 (Point-Conditioned Structure DiT MeanFlow) predicts active voxel occupancy grids, followed by Stage 2 (Sparse Vertex SDF Rectified Flow) predicting continuous 1D Signed Distance Fields decoded into watertight triangle meshes via Differentiable Marching Cubes.
